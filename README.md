# shop-tracker

## Terminal data entry

Run `node addUnit.js` to enter a new unit. Follow the prompts, review the table, and type `y` to save or `n` to cancel. Unit numbers must be unique positive integers; status is selected from a numbered list.

Data is saved in `units.json` and remains available after closing the terminal. Run `node summary.js` to display all saved units. Use one data-entry session at a time.

Shop Tracker is a webapp that will allow for easy management of Fleetco customer vehicles. It provides important information such as model, make, year, and status to ensure that Fleetco has the tools it needs to efficiently run their business digitally.

//How to run program
Shop Tracker can be run by downloading summary.js in my github repository. Then right click on the file and open in terminal. From there make sure Node.js is installed. If not visit https://nodejs.org/en/download. In the terminal, type node summary.js which will run the javascript file and display the data.
